# 千川 ROI 实时监控告警（Chrome 插件）

支持在 **巨量千川 / 抖店罗盘 / 巨量引擎 / 任意网页** 上秒级监听 ROI 数值，突破你设置的**上限值**或**下限值**时立即推送到 **企业微信（可在个人微信直收）/ PushPlus 个人微信 / 飞书 / 钉钉 / Bark / 电脑桌面弹窗+提示音**。

---

## 一、安装（1 分钟）

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/` 并回车。
2. 打开右上角 **开发者模式**。
3. 点击左上角 **加载已解压的扩展程序**，选择本文件夹（`qianchuan-roi-monitor`）。
4. （可选）如果要在本地 `demo.html` 测试，点插件卡片里的 **详情** → 打开 **允许访问文件网址**。

---

## 二、怎么用

### 1. 在巨量千川页面使用
打开巨量千川后台（如 `qianchuan.jinritemai.com`）后，页面右上角会自动出现 **「ROI 监控」悬浮胶囊**（如果在其他自定义网页上，点击浏览器右上角插件图标即可呼出）。

- **整体 + 多计划（默认，两个同时盯）**：同时监控页面上的**整体 ROI**（支持自动查找或一键点选页面数字，秒级监听）+ **计划列表里多条计划的 ROI**（自动识别表格列，支持最低消耗门槛防误报和可选定时点页内“刷新”）。
- 也可以随时切换到 **仅整体 ROI** 或 **仅计划列表** 模式。

### 2. 配置手机微信推送（二选一，也可多开）

- **企业微信群机器人（推荐：免费不限量，最稳）**
  1. 在企业微信建一个群（哪怕只有你自己），点击群右上角 → **群机器人 → 添加机器人**，复制 `Webhook` 地址。
  2. 粘贴到插件的 **企业微信群机器人 Webhook** 输入框，点 **「发送测试推送」**。
  3. 想直接在**个人微信**收提醒：手机微信关注/进入企业微信的 **微信插件**，打开消息提醒即可。

- **PushPlus 推送加（直达个人微信服务号，免费 200 条/天，需实名）**
  1. 打开 [pushplus.plus](https://www.pushplus.plus/) 微信扫码登录并完成实名，复制你的 `token`。
  2. 粘贴到插件的 **PushPlus Token** 输入框，点 **「发送测试推送」** 即可在个人微信收到测试消息。

---

## 三、快速本地测试

把 `demo.html` 拖进 Chrome 浏览器（先开启插件的“允许访问文件网址”），点页面里的 **「模拟跌破下限」/「模拟突破上限」** 按钮，即可立即验证实时捕获、提示音、桌面弹窗和微信推送。
