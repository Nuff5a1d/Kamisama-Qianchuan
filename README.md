# 千川 ROI 实时监控告警（Chrome 插件）

支持在 **巨量千川（全域推商品 / 推直播间 / 标准投放）/ 抖店罗盘 / 巨量引擎 / 任意网页** 上秒级监听 ROI 数值与页面健康状态，突破你设置的**上限值**或**下限值**、或出现**登录失效 / 页面报错 / 数据断流**时立即推送到 **企业微信（可在个人微信直收）/ PushPlus 个人微信 / 飞书 / 钉钉 / Bark / 电脑桌面弹窗+提示音**。

---

## 一、核心能力（v1.2.0）

- **全场景千川表格 & 指标卡精准适配**：
  - 兼容**千川乘方（商品视图 / 计划视图 / 调控任务详情页）**、**全域投放（推商品 / 推直播间）**、标准投放及虚拟滚动 `<div>` / ARIA 表格。
  - 顶部整体 ROI 指标卡直连 `.aurora-qc-statistic` / `.oc-promotion-metric-card`，按页面路径独立记忆绑定并带卡片标题防串位校验（视图切换绝不误把消耗读成 ROI）。
  - 自动匹配「调控综合营销ROI / 综合营销ROI / 整体支付ROI / 直接支付ROI」，支持「任务名称 / 抖音号 / 商品信息 / 计划」自动清洗，并内置 **`仅“投放中”`** 与 **`仅“调控中”`** 双默认勾选过滤。
- **表内多维高亮 + 顺次巡检控制台**：
  - **ROI 越界**：ROI 列标红（`↓跌破下限`）或标橙（`↑突破上限`）。
  - **预算撞墙提醒**：自动读取「调控预算 / 投放设置·每日预算」（也支持整体消耗上限与单计划上限），消耗达到预警比例（默认 `80%`）消耗列标紫 **`⚡快撞预算`**，满 `100%` 标深红 **`🚨已撞预算`**，提醒及时加预算。
  - **灰保过保黄色标记**：自动识别状态列灰色「保」图标并标明黄 **`⚠️已过保`**（绿色「保」与无保图标不显示），防计划跑偏跑飞。
  - **异常明细顺次巡检**：默认严格按表格从上到下顺序排列（含 `#行号`），支持 **`全部 / 跌破 / 突破 / 撞墙 / 过保`** 筛选联动表格高亮、**`◀ 上一条 / 下一条 ▶`** 持久蓝框定位、面板标题栏拖动与一键 **「极简」** 巡检模式。
- **五大推送渠道三层持久化 + 精细推送开关**：
  - 企业微信、PushPlus、飞书/钉钉、Bark、桌面弹窗采用 **`chrome.storage.local` + `chrome.storage.sync` + `localStorage` 三层同步备份**与多标签页实时同步，刷新页面或重载扩展绝不丢失 Token，并支持历史输入标签一键切换。
  - 支持独立勾选 **`跌破推 / 突破推 / 撞墙推 / 过保推`**（未勾选方向仅表内标亮不推送）。
- **页面异常提醒 & 一键结构诊断**：
  - 检测登录态失效、页面/接口报错（忽略平台公告条）与数据断流卡死；右上角「复制诊断」输出脱敏 DOM 诊断 JSON（不含 Cookie / Token）。

## 二、安装与更新（1 分钟）

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/` 并回车。
2. 打开右上角 **开发者模式**。
3. 点击左上角 **加载已解压的扩展程序**，选择本文件夹（`qianchuan-roi-monitor`）。若已安装旧版，拉取最新代码后直接点插件卡片右下角的 **刷新图标** 即可生效。
4. （可选）如果要在本地 `demo.html` 测试，点插件卡片里的 **详情** → 打开 **允许访问文件网址**。

## 三、怎么用

### 1. 在巨量千川页面使用
打开巨量千川后台（如 `qianchuan.jinritemai.com` 全域投放 → 推商品 / 推直播间 / 标准投放）后，页面右上角会自动出现 **「ROI 监控」悬浮胶囊**（如果在其他自定义网页上，点击浏览器右上角插件图标即可呼出）。

- **整体 + 多计划（默认，两个同时盯）**：同时监控页面上的**整体 ROI**（支持自动查找或一键点选页面数字，秒级监听）+ **计划列表里多条计划的 ROI**（自动识别表格列，支持最低消耗门槛防误报和可选定时点页内“刷新”）。
- 也可以随时切换到 **仅整体 ROI** 或 **仅计划列表** 模式。

### 2. 配置手机微信推送（二选一，也可多开）

- **企业微信群机器人（推荐：免费不限量，最稳）**
  1. 在企业微信建一个群（哪怕只有你自己），点击群右上角 → **群机器人 → 添加机器人**，复制 `Webhook` 地址。
  2. 粘贴到插件的 **企业微信群机器人 Webhook** 输入框，点 **「发送测试推送」**。
  3. 想直接在**个人微信**收提醒：手机微信关注/进入企业微信的 **微信插件**，打开消息提醒即可。

- **PushPlus 推送加（直达个人微信服务号，免费 200 条/天，需实名）**
  1. 打开 [pushplus.plus](https://www.pushplus.plus/) 微信扫码登录并完成实名，复制你的 `token`。
  2. 粘贴到插件的 **PushPlus Token** 输入框，点 **「发送测试推送」** 即可在个人微信收到测试消息。

## 四、快速本地测试

把 `demo.html` 拖进 Chrome 浏览器（先开启插件的“允许访问文件网址”），可一键验证：
- Arco/Semi 拆分双 `<table>` 识别、`共3条计划` 汇总行排除、`目标ROI` 干扰列过滤、`1.25万` 消耗解析
- 模拟跌破下限 / 突破上限弹窗与推送
- 模拟登录态失效弹窗 / 页面接口报错提醒
